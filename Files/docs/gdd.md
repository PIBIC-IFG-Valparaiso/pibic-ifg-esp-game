# Game Design Document (GDD)

## 1. Project Overview

### 1.1 Title

**Linguistic Logistics**

### 1.2 Genre

Educational / Puzzle / Simulation /

### 1.3 Platforms

Web, Desktop (Linux, Windows), Android

### 1.4 Game Summary

The president of the United States suddenly decides that all trade must occur exclusively with Brazil. At **Polyglot Port** in São Paulo, logistics operations begin to break down due to language barriers.

The player assumes the role of **The Engineer**, responsible for restoring efficient cargo operations by solving industrial automation puzzles that require tecnical understanding and translating key vocabulary used in port operations.

This game is an educational tool developed within the context of a PIBIC-EM project hosted by the Federal Institute of Education, Science and Technology of Goiás, campus Valparaíso.

### 1.5 Core Experience

Players manage cargo logistics systems while interpreting multilingual client orders. Learning vocabulary becomes necessary to correctly route shipments, operate machinery, and maintain port efficiency.

### 1.6 Unique Selling Points

* Language learning integrated into automation puzzles
* Industrial port simulation environment
* Educational mechanics embedded directly into gameplay tasks
* Progressive difficulty combining vocabulary and system management

# 3. Educational Design

O objetivo é apoiar o ensino de Língua Inglesa para estudantes do Ensino Médio Técnico Integrado em Automação Industrial, utilizando princípios de game design e gamificação.

O jogo integra:

* Conteúdo técnico contextualizado
* Vocabulário especializado (ESP)
* Mecânicas interativas
* Feedback pedagógico estruturado

### 3.1 Educational Purpose

Teach logistics-related vocabulary and reinforce language comprehension through contextual gameplay.

### 3.2 Learning Objectives

Players should be able to:

* Recognize common technical terminology
* Understand basic instructions in english
* Associate vocabulary with real-world technical operations

### 3.3 Target Vocabulary and Concepts

Examples:

* Cargo;
* Container;
* Dock;
* Crane;
* Shipment;
* Inventory;
* Route.

### 3.4 Pedagogical Approach

* Contextual learning;
* Problem-based tasks;
* Reinforcement through repeated interaction.

### 3.5 Learning Integration

Language comprehension is required to operate equipment, route cargo, and complete objectives.

# 4. Core Gameplay

### 4.1 Core Gameplay Concept

Players solve logistics puzzles by interpreting multilingual order instructions and correctly managing automated cargo systems.

### 4.2 Player Goals

* Maintain port efficiency through mecanical automation;
* Route cargo correctly;
* Complete logistics tasks using proper vocabulary understanding.

### 4.3 Core Mechanics

* Cargo routing;
* Machine operation;
* Instruction interpretation;
* Puzzle solving.

### 4.4 Feedback Systems

* Visual indicators for correct/incorrect actions;
* Efficiency scores;
* Task completion feedback.

---

# 5. Gameplay Loop

### Primary Loop

1. Receive cargo task;
2. Interpret instructions;
3. Operate port systems;
4. Deliver cargo correctly;
5. Receive a reward and possibly a performance feedback.

### Success State

Cargo delivered correctly and port efficiency maintained for the day.

### Failure State

Client insatisfaction, caused by cargo misrouting, delays and/or incomplete task.
