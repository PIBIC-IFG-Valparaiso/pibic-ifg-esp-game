# 2. Foco da Observação | Observation Focus

## Dimensão 1 – Interação com o Jogo

* Facilidade de navegação
* Compreensão das instruções em inglês
* Tempo de resposta
* Uso de tentativas múltiplas

## Dimensão 2 – Engajamento

* Demonstra motivação?
* Expressões verbais de interesse/frustração
* Persistência diante de erro

## Dimensão 3 – Aprendizagem Linguística

* Reconhecimento de vocabulário técnico
* Uso contextual correto
* Transferência de conhecimento

## Dimensão 4 – Aspectos Técnicos

* Bugs identificados
* Problemas de interface
* Dificuldades mecânicas

# 🔎 Orientações Metodológicas

Este instrumento está alinhado com:

* Observação participante (Angrosino)
* Geração de dados qualitativos (Flick)
* Codificação temática (Gibbs)

O preenchimento deve ocorrer imediatamente após a sessão para evitar perda de detalhes.
